# 原文

存储带宽一直是前端设计中的重要掣肘，所以涉及到数据结构，需要分析清楚访问率需求。  
REG 搭建的数据结构可以不写，因为 REG 可以支持的访问率是无限的。SRAM 的数据结构需要明确清楚最大访问率和平均访问率，SRAM 的最大访问率会决定 SRAM 的类型，1RW 的使用 SPRAM，1R1W 的的使用 TPRAM，超过 1R1W 的使用 TPRAM，但是性能存在瓶颈，需要在性能分析中说清楚解决办法。

例 1：一个数据路径上的 FIFO，读写总线位宽是 32Byte，需要支持的带宽是 100Gbps。这个 FIFO 在设计上支持每拍读每拍写，所以最大访问率就是 1R1W；从带宽上计算，32Byte 的总线 100Gbps 带宽下的数据平均有效率为 100Gbps/s/32 * 8bit≈391MHz，如果时钟频率是 700MHz，平均的预期访问率就是 391/700≈0.56，平均访问率就是 0.56R0.56W。

例 2：一个控制路径模块中的表项，每包会进行一次读取操作，CSR 会配置这张表。由于 CSR 配置的间隔会很长，在计算访问率时可以忽略。理论上该模块可以每拍处理一个包，因此最大访问率就是 1R。平均访问率方面，如果该模块看到的包率与包长相关，以芯片承诺支持性能的规格中最坏的情况为准，比如 256 字节下包率最高，达到 905MHz，工作时钟 930MHz 那么这个表项的平均访问率就可以认为是 905/930≈1，即平均访问率也可以填写 1R。

例3：对于一些逻辑处理可以保证 TDM 的表项，比如逻辑实现上分配了时隙，非常均匀的
每两拍才会有一次读或者一次写，那么最大访问率就是 0.5RW，平均访问率可以根据带宽/
包率等再参考上面的例子进行计算。

需要说明的是，在 SRAM 选型时，能选对 SPRAM 就尽量不要选择 TPRAM，因为在同等
规格情况下后者面积是前者的两倍。具体来说，如果模块的处理上，可能最大提供到 1R1W
的 BURST 处理能力，但是经过计算这个带宽已经达到了性能需求的 2 倍以上，选型上就可
以退为选择 SPRAM，只提供 1RW 的能力，虽然 BRUST 处理性能下降，但对于平均性能
仍然是有余量的。针对这种情况举个例子：某模块是按照 2KB 的固定粒度来处理数据，不
感知包长（控制路径模块如果引入粒度化处理就会有这种情况），每次处理需要对表项进行
一次读和一次写，假设时钟频率 1.2GHz，总性能需求假设是 4.8Tbps。如果使用 TPRAM，
所能提供的 BURST 处理能力达到 1.2 * 2 * 8=19.2Tbps，这个带宽已经达到需求的 4 倍，是
不必要的。如果换用 SPRAM，因为 SRAM 的访问率限制，只能做到两拍处理一次，所提
供的 BURST 片时性能达到 1.2*2*8/2=9.6Tbps，仍然有 2 倍的加速比，完全可以满足需求。

# 优化版

> 本文档说明前端设计中存储带宽的分析方法与 SRAM 选型原则，指导工程师在满足性能需求的前提下，合理选择存储类型以平衡性能与面积。

## 1. 概述

存储带宽是前端设计中的重要掣肘。涉及数据结构的模块，必须分析清楚访问率需求。不同存储介质的访问率特性差异显著：

- **REG 搭建的数据结构**：访问率视为无限，无需额外分析。
- **SRAM 的数据结构**：需明确 **最大访问率** 和 **平均访问率**，前者直接决定 SRAM 类型选择：
  - 1RW → 使用 **SPRAM**
  - 1R1W → 使用 **TPRAM**
  - 超过 1R1W → 仍需使用 TPRAM，但存在性能瓶颈，须在性能分析中说清解决办法 [^1]。

## 2. 核心原则：优先选用 SPRAM

> **在满足性能需求的前提下，能选 SPRAM 就不要选 TPRAM。** 同等规格下，TPRAM 面积是 SPRAM 的两倍 [^1]。

若某模块最大可提供 1R1W 的 BURST 处理能力，但经计算该带宽已达性能需求的 **2 倍以上**，则可退选 SPRAM（仅提供 1RW 能力）。虽然 BURST 处理性能下降，但平均性能仍有余量。

## 3. 访问率计算示例

### 例1：数据路径 FIFO

- **总线位宽**：32 Byte
- **需求带宽**：100 Gbps
- **设计能力**：支持每拍读、每拍写 → 最大访问率为 **1R1W**
- **时钟频率**：700 MHz

**平均访问率计算**：
1. 数据平均有效率：100 Gbps ÷ (32 Byte × 8 bit/Byte) ≈ 391 MHz
2. 平均周期有效率：391 MHz ÷ 700 MHz ≈ 0.56
3. **平均访问率**：0.56R0.56W [^1]

### 例2：控制路径表项

- **访问模式**：每包一次读取，CSR 配置间隔长（可忽略）
- **设计能力**：每拍处理一个包 → 最大访问率为 **1R**
- **最差包率**：256 字节下包率最高，达 905 MHz
- **工作时钟**：930 MHz

**平均访问率**：905 / 930 ≈ 1 → **1R** [^1]

### 例3：TDM 处理的表项

- **时隙分配**：逻辑保证每两拍一次读或一次写
- **最大访问率**：0.5RW
- **平均访问率**：根据带宽 / 包率等参考前两例计算 [^1]

> **TDM（Time Division Multiplexing）** 指通过逻辑实现时隙分配，使访问操作在时间上均匀分布，从而确定最大访问率，简化 SRAM 选型 [^1]。

## 4. 选型权衡示例

某模块按 **2 KB 固定粒度** 处理数据（不感知包长），每次处理需对表项进行一次读和一次写：

| 参数 | 数值 |
|------|------|
| 时钟频率 | 1.2 GHz |
| 总性能需求 | 4.8 Tbps |
| 每次处理操作数 | 1R + 1W（2 次操作） |
| 数据位宽 | 2 KB = 16,384 bits（隐含每次传输 8 Byte × 2 次操作中的位宽，原计算中简化为 8） |

**方案对比**：

| 存储类型 | BURST 处理能力计算 | 能力 | 与需求比 |
|----------|-------------------|------|----------|
| TPRAM | 1.2 GHz × 2 次 × 8 Byte × 8 bit/Byte | 19.2 Tbps | **需求的 4 倍**（浪费） |
| SPRAM | 1.2 GHz × 2 次 × 8 Byte × 8 bit/Byte ÷ 2（两拍一次） | 9.6 Tbps | **仍有 2 倍加速比**（满足需求） |

**结论**：使用 SPRAM 已完全满足需求，且面积仅为 TPRAM 的一半 [^1]。

## 5. 注意事项

- 单位约定：本文档中所有 `bps` 均指 **bit per second**，小写 b 代表比特 [^1]。
- 计算平均访问率时，应以芯片承诺的最坏规格（如包率最高条件）为准 [^1]。
- TDM 方式通过主动限制访问率，换取面积优势，适用于访问模式可预见的控制路径模块 [^1]。
