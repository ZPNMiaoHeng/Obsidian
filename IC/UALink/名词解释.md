## 5.9


| 缩写       | 全程                         | 功能                                           |
| -------- | -------------------------- | -------------------------------------------- |
| FTYPE    | Field type                 | 指示字段类型                                       |
| CMD      | Command                    | 保存 UPLI 命令值                                  |
| VCHAN    | Virtual Channel            | 虚拟通道                                         |
| ASI      | Address Space Identifier   | 地址空间标识符                                      |
| ATTR     | Attribute                  | ==属性==，保存 UPLI 相关属性值                         |
| SRCACCID | Source Accelerator ID      | 源加速器 ID 号，比如请求会保存 UPLI ReqSrcPhysAccID 信号值。  |
| DSTACCID | Destination Accelerator ID | 目的加速器 ID 号，比如请求会保存 UPLI ReqDstPhysAccID 信号值。 |
| CLOAD    | Cache Load                 | 指示是否把这个 TX 发出的信息缓存到 RX 处的地址 Cache？           |
| CWAY     | Cache Way                  | 指示数据保存在 Cache 哪一路                            |
| NUMBEATS | Number of Beats            | 节拍数。指示数据传输的节拍数                               |
