##### 动态寄存器配置
- ==解开 DDR 控制器的复位==；

| 基地址      | 配置数据                                  |
|:----------- | ----------------------------------------- |
| 320         | 'h0                                       |
| 1b0         | ‘h61                                      |
| 320         | 'h1'                                      |
| 延迟 100 ns |                                           |
| 324         | 读此寄存器的值，等待`rdata[0] == 1’b1`;   |
| 1bc         | 读此寄存器的值，等待`rdata[0] == 1’b1`;   |
| 320         | 'h0                                       |
| 1b0         | ’h41                                      |
| 320         | 'h1                                       |
| 延迟 100 ns |                                           |
| 324         | 无需等待。                                |
| 004         | 读此寄存器的值，等待`rdata[1:0] == 2’b1`; |
| 490         | ‘h1                                       |
| 490         | 读此寄存器的值，等待`rdata[0] == 1’b1`;   |
