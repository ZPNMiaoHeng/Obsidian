# 接口
##### 位宽
- 使用宏定义控制位宽大小；
#### 命名
- 端口名字尽可能公共，便于参数化使用；
##### req、ack
- 二者之前存在优先级，一般外界模块向次模块发送req信号，此模块响应通过ack；
- 脉冲信号；
- 二者无依赖；

| Name     | Description | IO     |
| -------- | ----------- | ------ |
| req      | 请求信号        | input  |
| req_data | 请求数据        | input  |
| ack      | 回应信号        | output |
| ack_data | 回应数据        | output |

##### valid
- 一般信号和数据配合使用，表示有效数据；
- 电平信号，由输入端控制；

| Name       | Description | IO    |
| ---------- | ----------- | ----- |
| valid      | 有效标识        | inout |
| valid_data | 有效数据        | inout |
