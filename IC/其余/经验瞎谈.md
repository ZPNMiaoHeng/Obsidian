## 精度丢失：
原因：**精度丢失 = 信息位被截断或错误表示**，主要发生在：
1. **存储位宽 < 计算所需位宽** → 高位截断
2. **有符号数用无符号方式处理** → 符号位丢失
3. **中间结果位宽不足** → 进位/借位丢失

**核心原则**：**每个操作的输出位宽应≥输入位宽的最大需求，显式处理扩展比依赖工具隐式规则更安全。**
### 常见场景及示例

#### 1. 加法/乘法溢出

```verilog
wire [2:0] a = 3'b111;  // 7
wire [2:0] b = 3'b011;  // 3
wire [2:0] sum = a + b; // 7+3=10(1010)，但只保留3位→010(2)，丢失进位
```
**问题**：3位无法存储需要4位的结果

#### 2. 减法产生负数
```verilog
wire [3:0] a = 4'b0010; // 2
wire [3:0] b = 4'b0100; // 4
wire [3:0] diff = a - b; // 2-4=-2，但无符号显示为14(1110)
// 期望-2，实际得到14，丢失符号信息
```

#### 3. 右移时的符号扩展
```verilog
wire signed [3:0] a = 4'b1011; // -5
wire [3:0] b = a >> 1;         // 算术右移？逻辑右移？
// 无符号右移：0101(5) 错误
// 有符号右移：1101(-3) 正确
```

#### 4. 位宽不匹配赋值
```verilog
wire [7:0] data = 8'hFF;
wire [3:0] small = data; // 丢失高4位，只保留F
```

### 经验法则

1. **加法规则**：N位 + N位 → 需要N+1位存储完整结果
2. **乘法规则**：M位 × N位 → 需要M+N位存储完整结果
3. **减法规则**：N位 - N位 → 需要N+1位存储有符号结果
4. **移位规则**：右移可能丢失低位，左移可能丢失高位
5. **拼接规则**：`{}` 只拼接不扩展，扩展需显式补位
