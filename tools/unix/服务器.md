###### 调整分辨率
注意需要查看服务器的名字 ，`VNC-0`或者是`defalut`；
```bash
xrandr # 查看服务器支持的分辨率
xrandr --output VNC-0 --mode 1920×1080 #修改当前分辨率
xrandr --output VNC-0 --mode 2560×1440_60.00 #修改当前分辨率
```

---

``` bash 
cvt 2560 1440 60 # 设置所需分辨率
xrandr --newmode "2560x1440_60.00" 312.25  2560 2752 3024 3488 1440 1443 1448 1493 -hsync +vsync # 将cvt输出的信息通过xrandr写入当服务器
xrandr --addmode VNC-0 "2560x1440_60.00" # 添加分辨率
xrandr --output VNC-0 --mode "2560x1440_60.00" # 切换新分辨率
``` 

``` bash 
cvt 3840 2160 60 # 设置所需分辨率
xrandr --newmode "3840x2160_60.00" 712.75  3840 4160 4576 5312  2160 2163 2168 2237 -hsync +vsync # 将cvt输出的信息通过xrandr写入当服务器
xrandr --addmode VNC-0 "3840x2160_60.00" # 添加分辨率
xrandr --output VNC-0 --mode "3840x2160_60.00" # 切换新分辨率
```
