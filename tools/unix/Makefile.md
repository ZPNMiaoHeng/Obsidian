# ⚠️
- `#` 表示注释内容；
	- ⚠️：`a:=b   # define a`，这种定义的 a 的值为b加上到`#` 之前的空格，如果定义目录就会产生错误。
- Makefile 中每一行都是单独命令，若想连续执行，则将命令放在同一行，使用`;`隔开
	- `cd src；pwd`：就会显示 src 的路径，否则只会显示 Makefile 所在的路径； 
- 变量定义：
	- =，无序，可以在文件中任意位置；
	- :=，有序，前面变量不能使用后面变量；
	- ?=，未定义时定义，定义的话忽略赋值；
	- +=，追加变量值；
- `CFLAGS`：Makefile 中环境变量，未定义使用系统环境变量；
