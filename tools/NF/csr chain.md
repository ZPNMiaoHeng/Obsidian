#tools #NF 
- 目的：软件可以通过csr chain读写csr寄存器，从而修改硬件配置；
##### 端口

| name            | width  | description                   |
| --------------- | ------ | ----------------------------- |
| reg_chain_valid | [0:0]  | 1`b1：表示本次数据有效；                |
| reg_chain_code  | [0:0]  | 1‘b1：写操作；1’b0：读操作；            |
|                 | [1:1]  | 1'b1：`读回应`/`写完成`；1'b0：普通读写操作； |
|                 | [2:2]  | 1'b1：表示DMA模式；                 |
| reg_chain_addr  | [21:0] | 根据项目，可以更改addr位宽；              |
| reg_chain_data  | [31:0] | 传输数据；                         |
1. 写操作过程：当需要往`a`节点写入数据，`csr ctrl`首先会解析`valid`和操作类型`（code）`；
	1. 若`写完成`和`读响应`，则直接输出数据；
	2. 若读写操作，对当前节点访问相对应寄存器；
2. 写完成：访问寄存器时，同时将`code`变为`写完成`，后续节点也不会解析此拍数据；
3. 读操作类似，会传输一个读数据；
