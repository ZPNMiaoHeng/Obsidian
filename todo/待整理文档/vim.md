# 数据整理
##### 实例化端口
- 正则表达式：
- 要对多行执行操作，使得每一行的点（`.`）后面的内容被复制并添加到行尾，同时使用括号包围，你可以使用 Vim 的全局命令结合替换功能。以下是一个步骤说明，它将对整个文件中的所有行执行此操作：

1. 进入命令模式，使用以下命令：
   ```
   :%s/\.\(.*\)/.\1(\1)/g
   ```
   这里是命令的详细解释：
   - `:`：进入命令模式。
   - `%`：表示对所有行执行以下命令。
   - `s`：表示替换操作。
   - `/\.\(.*\)/`：搜索模式，匹配每一行中的 `.` 及其后面的所有内容。这里 `.` 需要转义，因为在正则表达式中它是一个特殊字符，所以使用 `\.`。`\(.*\)` 是一个捕获组，它匹配 `.` 后面的任意字符，并将这些字符捕获起来，以便在替换时可以使用。
   - `.\1(\1)`：替换模式，`.` 保持不变，`\1` 引用第一个捕获组的内容（即 `.` 后面的内容），`(\1)` 将捕获的内容用括号包围。
   - `g`：全局标志，表示对每一行中的所有匹配项都执行替换。

这个命令会遍历文件的每一行，查找每个 `.` 及其后面的内容，然后将这些内容复制到行尾，并用括号包围起来。

请注意，这个命令假设每个 `.` 后面都有内容，并且你希望将这些内容复制到行尾。如果 `.` 后面没有内容，或者你只想对特定的行或行范围执行此操作，你可能需要调整命令或使用更复杂的正则表达式。

##### 删除行中括号里的内容
-  正则表达式：删除选中行里的括号以及其内容
	- `%`：表示对整个文件进行操作。
		- 或者 选中行后再进入命令模式；
	- `s`：表示替换操作。
	- `/(\s*\([^)]*\))//g`：正则表达式部分。
	    - `\(\s*\)`：匹配零个或多个空白字符，并将它们作为一个捕获组。
	    - `\([^)]*\)`：匹配一个左圆括号 `(`，然后匹配任意数量的非右圆括号字符（`[^)]*`），最后匹配一个右圆括号 `)`。
	    - `//`：将匹配到的内容替换为空（即删除它们）。
	    - `g`：全局替换，即对每一行中的所有匹配项进行替换。
