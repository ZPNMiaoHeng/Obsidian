## 引言
- 本 IP TMTCAMS012AAA 是一款同步高密度三态内容可寻址存储器编译器，基于中芯国际 12nm SFe 工艺实现。
- 通过该编译器，可生成多种不同配置的存储实例。它能够提供业界领先的模型视图，包括数据手册、Verilog 行为仿真模型、以及用于 ASIC 设计的布局布线模型。
- 这款全定制 TCAM 编译器在最小化面积的同时，可提供卓越的性能和功耗。使用该编译器可最大程度地缩短设计周期并降低设计风险。

## 特性
1. 完全定制和优化布局，以实现最小面积
2. 配置范围：32×4 至 512×160
3. 自动漏电控制技术，降低待机电流
4. 余量调整选项，用于速度/良率优化
5. 使用两个阵列（数据阵列和掩码阵列）来编码 0、1 或 X 值
6. 写操作中支持位写掩码
7. 比较操作中支持键掩码
8. 通过配置 bank 使能引脚降低动态比较功耗
9. 包含 `Match/Miss` 标志
10. 直接 HITLINE 输出
11. 流水线输出：读延迟 = 1；比较 HITLINE 输出延迟 = 1；比较 HIT 输出延迟 = 2
12. 工作电压 0.8 V ±10%
13. 存储器编译器预览 UI——Meminder 可用
14. IP 金属层使用：5 层金属
15. 支持 LVT/ULVT 外围电路

## 三、 CLN6FF tcam功能描述

### 1、tcam 读操作

- 读延时1个cycle。
- 读操作时，CEB为low，RW为high，CMP为low，RST为low。
- 读地址由A[m-1:0]来传入，读数据由Q[W-1:0]传出。
- 由MD来区分读data还是读mask，data和mask不能同时读。
- 当需要读tcam_entry valid时，CEB为low，VBE为high，CMP为low，RST为low。
- 读地址由A[m-1:0]来传入，读数据由VBO传出。
- 读valid不可单独读，必须伴随data或者mask一起读。

### 2、tcam写操作

- 写延时1个cycle。
- 写操作时，CEB为low，RW为low，CMP为low，RST为low。
- 读地址由A[m-1:0]来传入，写数据由D[W-1:0]传入。
- 由MD来区分写data还是写mask，data和mask不能同时写。
- 写tcam时还需关注MASKB信号，MAKSB[i]为0时，tcam_entry[i]不会被写入。
- 当需要写tcam_entry valid时，CEB为low，VBE为high，CMP为low，RST为low。
- 写地址由A[m-1:0]来传入，写数据由VBI传入。
- 写valid不可单独写，必须伴随data或者mask一起写。

### 3、tcam 查表操作

- 查找延时1个cycle。
- 查表操作时，CEB为low，CMP为high，RST为low。
- 只有tcam_entry 的valid标志位为1，且对应的CBE enable为高时，该entry才会被用于查表。
- tcam_entry中mask为0的bit位在比较时会被忽略。
- 查表结果由ML[r-1:0]输出。
- 查表操作生效时，读写操作均会失效。

### 4、valid reset操作

- valid reset操作延时1个cycle。
- valid reset操作时，CEB为low，RST为high。
- valid reset操作将所有tcam_entry 的valid信号置为0.
- valid reset操作生效时，tcam查找，tcam读，tcam写均失效。

## 四、 CLN6FF tcam的冗余队列

CLN6FF tcam的冗余队列一般用于tcam的错误检测及纠错，是保证tcam可靠性一种手段。在 TCAM 会中额外设置一定数量的 "冗余列"，它们与正常数据列的结构完全相同。每个数据行可以通过内部地址映射机制选择使用正常列或冗余列。当检测到某列出现故障时，系统会将该列的功能切换到冗余列上。

举个例子来说，某个tcam的数据位宽为80 bits，在tcam内部通常预留的位宽会比80 bits多一些，假设预留的是82 bits。当流片回来之后，通过测试发现第5 bit位置对应的那一列有缺陷，此时tcam就会从先前多预留的列里面选出一列来代替第5列。在这一过程中，只需要从tcam的接口上告诉tcam哪一列有问题即可，其内部的替换逻辑对使用者来说完全透明。那么如何告诉tcam那一列有问题呢？这就需要用到前文提到的接口FIO，FIO[i]=1，即指明i列存在缺陷。此时，尽管该tcam的第5列不能使用，但是该tcam依然是可用的。

### 命名格式
```
Prefix_wordXbitMuxWordwriteBusmode
```
即：**前缀_字数X位数M多路选择器字写模式总线模式**

---

### 前缀规则（Prefix）
前缀固定部分为 **TMTCAMS012AAA**，各部分含义如下：

| 段 | 值 | 说明 |
|----|----|------|
| 产品系列 | TM | 存储器产品 |
| 产品子系列 | TCAM | TCAM（三态内容可寻址存储器） |
| 代工厂 | S | SMIC（中芯国际） |
| 工艺节点 | 012 | 12nm |
| 工艺特性 | A | 通用（Generic） |
| 位单元类型 | A | 通用 |
| 客户 | A | 面向代工厂 |

前缀后接版本号和冗余选项，格式为 **\_VnRm**：
- **Vn**：版本号，`n` 取值：
  - `1`：主要器件为 LVT + ULVT + SVT 混用
  - `2`：主要器件为 ULVT + LVT + SVT 混用
- **Rm**：冗余方案，`m` 取值：
  - `0`：无冗余
  - `2`：带列冗余

组合示例：`V2R2` 表示版本2（Mainly ULVT）、带列冗余。

---

### 实例体规则
在 `_` 之后定义存储容量和功能模式：

**word**：字数（深度）  
**bit**：位数（宽度）  
**M** + 数字：宽高比（aspect ratio）编号，如 `M1`  
**wordwrite**：写模式  
- `W1`：字写（word write）  
- `W0`：位写（bit write）  
**busmode**：总线模式  
- `F0`：无总线模式  
- `F1`：带总线模式（手册此处标记为 `[ ] busmode`，可能为预留选项）

---

### 示例解读
**TMTCAMS012AAA_V2R2_512X80M1W0F0**

- TMTCAMS012AAA：TCAM IP 基础前缀（12nm SMIC 通用工艺）
- V2R2：版本2（主要ULVT），带列冗余
- 512X80：512 字 x 80 位
- M1：宽高比选项1
- W0：位写模式
- F0：无总线模式

即：**一款 512x80 的高密度 TCAM，宽高比1，支持位写，无总线模式，带列冗余，外围器件以 ULVT 为主**。
