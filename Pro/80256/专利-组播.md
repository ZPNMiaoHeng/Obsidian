
## NT组播 
	NT endpoint也有multicast capability配置空间，如果NT endpoint通过配置 MC Receive加入了某些组播组MCG,当Host发出一个组播报文，命中了NT endpoint的MC_Receive组播组，也要向NT endpoint组播，向NT endpoint组播并不是要把报文发送给NT endpoint,.而是要通过NT endpoint向其它Host所在的vCs组播； 
	80256NT组播分为四种情况：
	(1)向本VCS内的端口进行组播复制（普通PCle组播）；
	(2）向本switch内的其它VCS的端口进行组播复制（跨VCS复制，不需要出 switch进入Fabric网络)
	(3)向其它switch的NT endpoint进行组播复制（出switch进入Fabric网铬）；
	(4)其它NT endpoint向它所在的VCS端口进行组播复制（普通Pcle组播）；

NT组播实现步骤：

NT endpoint 也有 multicast capability 配置空间，如果 NT endpoint 通过配置 MC_Receive 加入了某些组播组MCG，当Host发出一个组播报文，命中了 NT endpoint 的 MC Receive 组播组，也要向 NT endpoint 组播.向 NT endpoint 组播并不是要把报文发送给 NT endpoint，而是要通过 NT endpoint 向其它 Host 所在的 VCS 组播.

NT组播实现步骤：
1. 软件初始化： 
	1. 配置 NT endpoint multicast capbility，使能 NT endpoint 组播；
	2. NT_MCG：每位指示对应NT节点是否加入该MCG；
	3. NT_num:指明 VCS 到 NTE 编号的映射； 
	4. ID Mapping table：BDF 匹配后得到对应 SPID 信息； 
	5. NT_Bitmap_2_DPID
2. NTB 收到 host 的组播报文，检查组播报文的地址，如果命中 NT endpoint 组播地址说明要进行 NT 组播，计算组播组 MCG 号；计算规则为：
	1. MC_Enable有效；
	2. 报文是内存写或者地址路由消息报文，并且两者都是转发请求；
	3. 报文地址>=MC_Base_address; 
	4. 报文地址<(MC_base_address+(2Mc tior*(MC_Num_Group+1))）。
3. NTB 根据组播组 MCG 号判断对应的 NT_Receive 是否为 1，
	1. 若为 1 ，说明要向这个 NT endpoint 组播。
	2. 得到 64 位的 NT_bitmap[63:0]，每 1bit 表示是否要组播到对应的NTendpoint；
4. 访问 NTB NT endpoint 编号寄存器，使用 VCS 号索引得到 NT endpoint 编号 NT_num；
	1. 如果 NT_num对应的NT_bitmap有效，则表示要在本 switch 内组播到该 VCS，并记录到 NT_VCS_bitmap；
	2. 然后清除对应 NT_NUM 的 NT_bitmap 的比特位值，表示这些 NT endpoint 在本 switch 内组播，不需要通过 Fabric 网络的 Port 向其它 switch 的NT endpoint 组播；
	3. 将本 VCS 的 NT_num 对应 NT_VCS_bitmap 和 NT_bitmap 比特位清0，防止组播复制到本地，修改报文字段，并设置 NT 组播的命中标志；
5. 访问 NTB ID Mapping table 得到对应NT endpoint 的多组 SPID，用于后续 Slice 模块进行 NT 组播，NTB 模块重排序删除无效 SPID 后存入报文；
6. NTB 将报文送到组播模块，组播模块看 NT 组播标志有效,则根据 NT_VCS_bitmap 对应本Switch 内组播过滤；
7. slice 根据报文中的 NT_bitmap 每一位依次查 DPID 表，得到对应转发的目的 DPID/Dst NT_Bus/NToverlay/PPB，对报文进行 NT 组播复制，然后做 NT Overlay 地址转换和NT Requester ID 转换；
8. slice 组播复制后的 NT 组播报文根据端口号送给交换模块，最终经过Fabric Port端口发送出去，并且 NT 组播复制后的报文需要添加 Fabric NTB 标记，用来判断组播报文是否要组播给其它 NT endpoint，防止报文在 NT endpoint 间重复组播。
9. 其它 switch 的 Fabric Port 收到 NT 组播复制报文后，NTB 检查组播报文 Requester ID 的NT_Bus 等于自身的 VCS NT endpoint Bus号，并且报文中 Fabric NTB 字段是否有效；
	1. 若有效，说明是其它 NT endpoint 发过来的组播报文，只需要在本 VCS 内组播，设置将NT_MC字段清零后交给组播模块在本 VCS 内进行组播；
10. NT 组播报文与 NT 单播报文走了不同的路径，但是会在流水线出口重排序，所以不会出现乱序问题；
