# QA

- NTB 异常情况：
	-  id 表全局，addr 表由 host 控制；
	- 组播报文命中，但 mc_receive[MCG] 查到值为0，普通 PCIe 路由。
		- 单播与组播同时命中：组播优先；
		- 处理过程：
			- 当成组播处理；
			- bitmap为0，没有转发的 endpoint；
			- 丢弃处理；
			- 在哪里统计呢？遗留问题
	- Fabric 路由时，NTB 中查表得到的 SPID、DPID 表项中 Valid 无效；
		- Valid 是否有效决定路由方式：FBR 或者 PBR；
	- Doorbell 查表异常，命中 Doorbell 后，但在 msi_table 中读到 vcs，msi_addr/data
		- 添加 1bit 的 MSI_enable;
		- 若 MSI_enable=0，报文丢掉（打上 drop）；
		- 数据不重要，不用啦
