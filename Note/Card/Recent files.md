# 配置
- List length：支持管理最大记录的历史文件数量，默认 50，你可以调整的更大/更小，以便适应自己的文档查看习惯。
- Open note in：选择点击最近浏览列表的文件时，是以何种方式打开。比如标签页、窗口、面板。
- Omniited pathname patterns：可以过滤你不想看到的内容，比如文件夹、指定后缀名的文件。
# 日常使用
- 鼠标左键点击笔记，在当前标签页内打开；
- 按住Ctr加鼠标左键在全新标签页打开；
- 按住Ctr在鼠标指向的位置悬停展示对应笔记内容；
- 按住Ctr拖拽到笔记内部，可以建立内部链接；
- 按住Ctr拖拽到笔记文件管理器中，可以快速移动笔记位置。
