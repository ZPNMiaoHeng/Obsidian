#card 
- `DDRC clock(core_ddrc_core_clk)` 和 `memory clock`支持 1:1 和 1:2 频率比；
- 当参数 `MEMC_PROG_FREQ_RATIO=1`和`MEMC_FREQ_RATIO=2`时，HIF 数据总线是内存数据总线宽度四倍；
# 寄存器

|                      |                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------- |
| MSTR.frequency_ratio | 0x1：DDRC clock 速率和 memory 速率相同，频率比为1:1；<br>0x0：DDRC clock 速率是 memory 速率的一半，频率比为1:2； |
| MEMC_PROG_FREQ_RATIO | 频率比是否可编程<br>0x0：硬件使用 MEMC_FREQ_RATIO 指定，不可编程；<br>0x1：软件可编程，MSTR.frequency_ratio；    |
| MEMC_FREQ_RATIO      | 0x1：1:1，HIF 数据总线位宽为内存数据宽度两倍；<br>0x2：1:2，HIF 数据总线位宽为内存数据宽度四倍；                        |

# 举例
- 1:1 频率比模式下，若 `MEMC_PROG_FREQ_RATIO=0x1`，内存数据宽度为 32 bits，内存时钟为 400MHz 或者 800 Mbps，则 HIF 数据总线宽度为 128 bits，只使用了 DFI 总线的下半部分，DDRC clock 为 400MHz；
	- 若频率比改为 1:2，HIF 数据宽度为 128 bits，DFI 数据总线全部使用，DDRC clock 为 200Mhz；
- 1:1 频率比模式下，若 `MEMC_PROG_FREQ_RATIO=0x0`，内存数据宽度为 32 bits，内存时钟为 400MHz 或者 800 Mbps，则 HIF 数据总线宽度为 64 bits， DFI 总线全部使用，DDRC clock 为 400MHz；
