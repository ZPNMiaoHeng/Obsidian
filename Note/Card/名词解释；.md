# uart

| 缩写  | 全程                  | 功能     |
| --- | ------------------- | ------ |
| CTS | Clear To Send       | 清楚发送   |
| DCD | Data Carrier Detect | 数据载波检测 |
| DSR | Data Set Ready      | 数据集就绪  |
| RI  | Ring Indicator      | 振铃指示   |
| RTS | Request To Send     | 请求发送   |
| DTR | Data Terminal Ready | 数据终端就绪 |
| SIR | Serial InfraRed     |        |
