## 3. Calendar/Periodic Notes 插件配置

在你的 `.obsidian/plugins/periodic-notes/data.json` 中配置：

```json
{
  "daily": {
    "format": "YYYY-MM-DD",
    "template": "/Note/Templete/Daily temp.md",
    "folder": "/Note/Templete/Daily/",
    "enabled": true
  },
  "weekly": {
    "format": "YYYY-[W]W",
    "template": "/Note/Templete/Weekly temp.md",
    "folder": "/Note/Templete/Weekly/",
    "enabled": true
  }
}
```

## 4. Tasks 插件配置建议

确保 Tasks 插件已正确安装并启用。在周报中规划任务时，使用以下格式：
```
- [ ] 任务描述 📅 YYYY-MM-DD
```

## 5. 使用流程

1. **每周初**：使用 Calendar/Periodic Notes 创建周报
2. **规划任务**：在周报中按天规划任务，使用 `📅 YYYY-MM-DD` 格式设置截止日期
3. **每日**：使用 Calendar/Periodic Notes 创建日报
4. **自动提取**：日报中的 Tasks 查询会自动显示当天到期的周报任务

## 6. 注意事项

1. **路径确认**：确保你的实际路径与配置一致
2. **插件版本**：确保 Templater、Tasks、Calendar/Periodic Notes 插件都是最新版本
3. **Tasks 语法**：周报中的任务必须使用正确的 Tasks 插件语法
4. **日期格式**：保持日期格式的一致性（YYYY-MM-DD）

这个系统会自动将周报中规划的任务按日期拆分到对应的日报中，实现任务管理的自动化。你需要做的就是每周规划好任务，然后每天查看日报即可看到当天的任务列表。
