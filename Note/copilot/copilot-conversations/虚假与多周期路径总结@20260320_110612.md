# **BES时序约束思维导图**

## **1. 基础概念**
- **时序路径 (Timing Path)**
  - 起点：时钟端口、输入端口
  - 终点：时钟端口、输出端口
  - 类型：寄存器到寄存器、输入到寄存器、寄存器到输出、输入到输出
- **时钟定义 (Clock Definition)**
  - 主时钟 (Primary Clock)
  - 生成时钟 (Generated Clock)
  - 虚拟时钟 (Virtual Clock)
- **时序检查 (Timing Check)**
  - 建立时间 (Setup Time)
  - 保持时间 (Hold Time)
  - 恢复时间 (Recovery Time)
  - 移除时间 (Removal Time)

## **2. 关键约束类型**
### **2.1 虚假路径 (False Path)**
- **定义**：逻辑存在但功能永不激活的路径
- **约束命令**：
  ```tcl
  set_false_path -from [get_clocks clkA] -to [get_clocks clkB]
  set_false_path -through [get_pins mux/sel]
  ```
- **应用场景**：
  - 跨时钟域 (CDC) 异步路径
  - 复位/测试模式路径
  - 多路选择器未激活分支
  - 伪功能逻辑路径
- **注意事项**：
  - 需配合CDC同步器设计
  - 避免过度约束掩盖真实时序问题

### **2.2 多周期路径 (Multi-Cycle Path)**
- **定义**：数据需要多个周期才能稳定的路径
- **约束命令**：
  ```tcl
  # N周期建立时间
  set_multicycle_path N -setup -from [get_pins ...] -to [get_pins ...]
  # 对应保持时间调整（通常N-1）
  set_multicycle_path N-1 -hold -from [get_pins ...] -to [get_pins ...]
  ```
- **应用场景**：
  - 低速运算单元（乘法器、除法器）
  - 使能信号控制的数据路径
  - 同步跨时钟域（慢→快）
  - 迭代计算逻辑
- **关键原则**：
  - 建立时间N周期 → 保持时间检查前移(N-1)周期
  - 必须同时约束建立和保持时间

### **2.3 最大/最小延迟约束 (Max/Min Delay)**
- **定义**：指定路径的绝对时间约束
- **约束命令**：
  ```tcl
  set_max_delay 5.0 -from [get_ports A] -to [get_ports B]
  set_min_delay 1.0 -from [get_ports A] -to [get_ports B]
  ```
- **应用场景**：
  - 纯组合逻辑路径
  - 异步接口时序
  - 特殊时序要求路径
  - 输入/输出延迟约束

## **3. 时钟约束**
### **3.1 时钟定义**
```tcl
# 主时钟
create_clock -name clk -period 10 [get_ports clk_in]

# 生成时钟
create_generated_clock -name clk_div2 \
  -source [get_ports clk_in] \
  -divide_by 2 [get_pins div/Q]

# 虚拟时钟
create_clock -name vclk -period 8
```

### **3.2 时钟不确定性 (Clock Uncertainty)**
```tcl
set_clock_uncertainty -setup 0.2 [get_clocks clk]
set_clock_uncertainty -hold 0.1 [get_clocks clk]
```

### **3.3 时钟组 (Clock Groups)**
```tcl
# 异步时钟组
set_clock_groups -asynchronous \
  -group {clkA} \
  -group {clkB}

# 互斥时钟组
set_clock_groups -exclusive \
  -group {clk1 clk2}
```

## **4. 输入/输出约束**
### **4.1 输入延迟 (Input Delay)**
```tcl
set_input_delay -clock clk -max 3.0 [get_ports data_in]
set_input_delay -clock clk -min 1.0 [get_ports data_in]
```

### **4.2 输出延迟 (Output Delay)**
```tcl
set_output_delay -clock clk -max 4.0 [get_ports data_out]
set_output_delay -clock clk -min 2.0 [get_ports data_out]
```

## **5. 特殊情况处理**
### **5.1 跨时钟域 (CDC) 约束策略**
- **异步CDC**：
  ```tcl
  # 设false path + 同步器设计
  set_false_path -from [get_clocks clk_src] -to [get_clocks clk_dst]
  ```
- **同步CDC**：
  ```tcl
  # 可能需设multi-cycle
  set_multicycle_path 2 -setup -from [get_clocks clk_slow] -to [get_clocks clk_fast]
  ```

### **5.2 复位路径约束**
```tcl
# 复位信号设为false path
set_false_path -from [get_ports rst_n]

# 或使用case analysis
set_case_analysis 0 [get_ports test_mode]
```

### **5.3 组合逻辑环路**
```tcl
# 禁止组合逻辑环路
set_disable_timing [get_cells comb_loop*]
```

### **6.1 约束检查清单**
- [ ] 所有时钟正确定义
- [ ] 时钟关系明确（同步/异步）

### **6.2 常见问题与调试**
- **过度约束**：时序过紧，面积功耗增加
- **约束不足**：时序违例未被检出
- **约束冲突**：矛盾约束导致工具困惑

### **6.3 验证方法**
