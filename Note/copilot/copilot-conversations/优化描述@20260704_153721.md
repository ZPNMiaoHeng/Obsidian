## table 规格汇总表单填写说明

1. **确认**：各模块设计人员梳理本模块所使用的全部 table，在《table 规格汇总表单》中逐行填写对应信息。

2. **填写字段说明**：
   - **Harden**：填写模块当前所属 Harden 名称。
   - **实例化模块**：填写该 table 的实例化（存放）位置，即 table 归属于哪个模块。
   - **使用模块**：填写所有访问该 table 的模块名称。
     - **多模块场景**：使用数字序号标记各模块，并换行填写。后续 `Design`、`描述` 等字段内容需与序号一一对齐。
   - **Design**：填写各使用模块的**设计负责人**。
     - **多模块场景**：设计人员按对应模块序号依次填写，以数字序号隔开。
   - **Protocol**：填写该 table 的**协议负责人**。
   - **访问需求**：填写该 table 所需的**接口组数**（不含 CSR 接口）。
   - **描述**：说明各模块使用该 table 的具体方式。
     - **单模块、单端口**场景可省略不填。
     - **多模块**场景需按模块序号、结合实际使用规则逐项描述。

---

**优化要点说明**：
- **"确认"**：补充了责任主体和执行方式，使其更具操作性。
- **"实例化模块"**：明确该字段表示 table 的物理归属，强化与"使用模块"的区分。
- **"Design"**：将“各访问模块的设计负责人”简化为“各使用模块的设计负责人”，并补全多模块填写规则。
- **"Protocol"**：补全为“协议负责人”，表述更规范。
