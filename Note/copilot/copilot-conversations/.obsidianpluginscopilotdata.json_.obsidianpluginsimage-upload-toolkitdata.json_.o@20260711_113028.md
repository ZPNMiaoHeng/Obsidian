## 📌 关键说明

1. **`.obsidian/plugins/*/data.json`**：如果想忽略所有插件的 `data.json`，可简写为：
   ```
   .obsidian/plugins/**/data.json
   ```

2. **已跟踪文件**：如果这些文件已被 Git 跟踪（之前 `git add` 过且已提交），加入 `.gitignore` 后不会自动停止跟踪，需执行：
   ```bash
   git rm --cached -r <文件或文件夹路径>
   ```
   例如：
   ```bash
   git rm --cached -r .obsidian/plugins/copilot/data.json
   git rm --cached -r IC/Reference/
   git rm --cached -r Note/copilot/
   ```

3. **推荐添加（可选）**：Obsidian 仓库常忽略的配置：
   ```gitignore

   ```
